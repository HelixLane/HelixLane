# Islands 工作台预览

用户选择固定区域方案，希望直接查看效果。以当前 Rust + GPUI Kit 应用为基础，提供可运行的深色 Islands 工作台。

## 方案与范围

选择固定区域和可调整分隔条，暂不采用自由停靠 DockArea，以便控制接近 IDEA 的外观。采用约 10px 圆角、5px 岛屿间距、略亮的外框底色和较暗的内容区域。保持 macOS 原生窗口按钮和标题栏拖动。

窗口默认 1440×900，最小 960×640。顶部为项目和分支信息、预览运行配置；左侧工具条切换 Project/Search；左侧工具面板显示可展开的示例文件树或项目文件筛选；中央为可切换、关闭的只读源码标签页；右侧工具条可打开文件信息；底部为可收起的 Terminal/Problems/Output 预览；底部状态栏显示实际选择的文件类型及预览状态。

示例文件来自编译时嵌入的本项目源码，不提供文件写入、真正终端、调试器或后台 Git 操作。预览不做跨启动布局持久化，该功能留待外观确认后实施。工具按钮有 tooltip，隐藏面板后可用同一工具按钮恢复。

## 实现

- `src/theme.rs`：集中视觉常量和岛屿容器。
- `src/editor.rs`：示例文件模型、只读源码和基础词法着色。
- `src/app.rs`：工作台状态、标题栏、工具条、文件树、标签、信息面板、底部预览和状态栏。
- `src/main.rs`：暗色主题、标题栏配置及窗口尺寸。

布局尺寸使用 GPUI Kit ResizablePanelGroup 管理，不手写拖动几何计算。各区域最小尺寸约束保证 960px 宽窗口可用；右侧信息面板为固定宽度，可收起。

## 验证

格式、cargo check、Clippy 和实际构建启动。尽可能仅捕获 HelixLane 应用窗口用于外观复核，不捕获桌面或其他应用。明确区分编译、启动与已观察的图形交互。
